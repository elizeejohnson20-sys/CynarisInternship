# Laravel API Integration

## Overview

This project demonstrates building and consuming a RESTful API using Laravel.

The API provides product CRUD operations and uses Laravel Sanctum for token-based authentication. A simple HTML/CSS/JavaScript frontend consumes the API using the JavaScript Fetch API.

## Technologies Used

- PHP 8.5
- Laravel 13
- Laravel Sanctum
- SQLite
- Eloquent ORM
- Laravel API Resources
- HTML
- CSS
- JavaScript
- Fetch API
- Postman
- Git
- GitHub

## Authentication

The API uses Laravel Sanctum personal access tokens.
