# Expense Tracker

A responsive expense tracker built using HTML, CSS, and JavaScript.

## Features

- Add expenses
- Select expense categories
- Calculate total expenses
- Delete expenses
- Save expenses using localStorage
- Restore expenses after refreshing the page
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6+
- DOM Manipulation
- localStorage
